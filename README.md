# Radionica kola ⚡

Simulator električnih kola na virtuelnom protobordu, za decu. Jezici: srpski, makedonski, rumunski, bugarski, engleski.

**Otvori aplikaciju:** https://programsedu.github.io/ekolo/

- 13 vrsta delova: žica, otpornik, LED, dioda, sijalica, zujalica, motor, taster, prekidač, potenciometar, fotootpornik, ampermetar, voltmetar
- Stvarni proračun struje i napona, pregorevanje LED-a, kratak spoj
- 15 lekcija koje se otključavaju redom + slobodna igra
- Čuvanje kola i deljenje kodom

## Izvorni kod
`index.html` je cela aplikacija u jednom fajlu. Delovi su u `src/`; posle izmene pokreni `cd src && python3 build.py`.
